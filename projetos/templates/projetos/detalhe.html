Visão geral: Cada projeto é composto por diversas fases, e cada fase é representada no sistema por uma Entrega. As entregas permitem acompanhar o progresso do projeto, registrar avanços, identificar atrasos e documentar a conclusão de cada etapa.

Como registrar uma nova fase (Entrega):

  1. No painel do projeto, clique em Adicionar Entrega.
  2. Informe o nome da fase (ex.: Diagnóstico, Planejamento, Implementação).
  3. Descreva brevemente o objetivo ou escopo da fase.
  4. Defina a data prevista para conclusão.
  5. Salve para registrar a nova fase do projeto.

Como registrar a conclusão de uma fase:

  1. Clique no botão Editar da entrega correspondente.
  2. Marque a opção Concluída.
  3. Informe a Data de Entrega (data em que a fase foi finalizada).
  4. Salve as alterações.

Ao salvar, o sistema irá automaticamente:

  • Atualizar o progresso geral do projeto;
  • Recalcular o status automático (Em andamento, Concluído, Atrasado);
  • Atualizar a barra de progresso com base nas fases concluídas;
  • Remover alertas de atraso da fase (se houver).

Observação importante: Não crie uma nova entrega para marcar a conclusão de uma fase já existente. A conclusão deve ser registrada diretamente na entrega correspondente.
